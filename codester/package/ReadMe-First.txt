QUICK INSTALLATION INSTRUCTIONS:
--------------------------------
DO NOT upload this entire Codester package to WordPress. 

To install the plugin:
1. Open the "Plugin" folder inside this package.
2. Locate the file: "appointpro.zip".
3. Log in to your WordPress Dashboard.
4. Go to: Plugins -> Add New -> Upload Plugin.
5. Select "appointpro.zip" and click "Install Now".
6. Click "Activate Plugin".
